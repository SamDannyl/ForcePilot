01 / Reuse setup

Saved recordings

Record a field setup once, then reuse it on compatible Salesforce records instead of repeating the same steps by hand.

Useful for

  • Finding saved setups by Salesforce object
  • Replaying field values on compatible records
  • Keeping recurring test preparation consistent

02 / Prepare test data

Randomization

Generate varied values for recorded fields to build test data without manually changing every input.

Useful for

  • Choosing a generator for each supported field
  • Previewing generated values before applying them
  • Using relative dates when scenarios need fresh dates

03 / Choose what to fill

Recorded fields

Review the values captured in a recording and decide how Autofill should apply them to the current record.

Useful for

  • Reviewing and editing recorded values
  • Controlling which fields are included
  • Filling only empty fields when needed

04 / Review outcomes

Autofill results

See the outcome field by field after a fill, so you can spot problems without inspecting every value manually.

Useful for

  • Checking filled, skipped, and failed fields
  • Finding values that need attention
  • Retrying unsuccessful fields when appropriate

05 / Keep work organized

Testing sessions

Keep a testing task together so you can start work, return to an existing session, and pick up where you left off.

Useful for

  • Starting a focused testing session
  • Resuming saved work instead of starting over
  • Keeping evidence connected to a test run

06 / Capture context

Testing workspace

Keep screenshots and supporting notes beside your testing work, rather than scattering context across separate places.

Useful for

  • Capturing screenshots during testing
  • Adding context to the evidence you collect
  • Reviewing test notes and visual proof together

07 / Share results

Evidence export

Take test evidence out of the browser in formats that are easier to review, archive, and share with a team.

Useful for

  • Exporting a structured Word document
  • Packaging screenshots in a ZIP file
  • Sharing a more complete testing record
