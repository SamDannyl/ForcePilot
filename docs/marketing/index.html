01 / Reuse field values

Saved recordings

Save Salesforce field values and reuse them on similar records instead of repeating the same setup by hand.

Useful for

  • Finding recordings by Salesforce object
  • Replaying values on compatible records
  • Keeping test preparation consistent

02 / Prepare test data

Randomization

Generate varied values for recorded fields without manually changing each input.

Useful for

  • Choosing a generator for each supported field
  • Using relative dates or a date range
  • Generating test values consistently

03 / Choose what to fill

Recorded fields

Review captured values and decide how Autofill should apply them to the current record.

Useful for

  • Reviewing and editing values
  • Selecting the fields to run
  • Filling only empty fields when needed

04 / Review outcomes

Autofill results

See the outcome field by field and identify values that need attention.

Useful for

  • Checking filled, skipped, and failed fields
  • Finding problems quickly
  • Retrying unsuccessful fields

05 / Keep work organized

Testing sessions

Start a testing task, return to saved work, and pick up where you left off.

Useful for

  • Starting focused sessions
  • Resuming saved work
  • Keeping evidence tied to a test run

06 / Capture context

Testing workspace

Keep test scenarios, screenshots, and their outcomes together while you work in Salesforce.

Useful for

  • Capturing screenshots during testing
  • Assigning captures to scenarios
  • Marking Pass, Fail, or Blocked

07 / Share results

Evidence export

Export your testing evidence in formats that are easier to review, archive, and share.

Useful for

  • Exporting a Word document
  • Packaging screenshots in a ZIP
  • Keeping a clear test record
